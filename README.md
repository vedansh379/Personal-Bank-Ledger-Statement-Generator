# Personal-Bank-Ledger-Statement-Generator
The Personal Bank Ledger & Statement Generator

 A Java based application designed to record and manage basic banking transactions.
 The system allows a user to enter details of deposits and withdrawals and maintains the transaction records using arrays.
The account balance is calculated and updated based on the transactions performed.
 Conditional statements are used to validate transactions, while loops are used to perform repeated operations and display transaction details.
 Arrays are used to store and organize transaction data, and recursion can be incorporated for repeated menu operations or transaction processing.
 The project aims to demonstrate the practical application of fundamental Java programming concepts such as arrays, if-else statements, loops, and recursion in a real-world financial management scenario.


Aim:

To develop a simple Java program that records banking transactions and generates a basic bank statement using fundamental programming concepts.

Objectives:
•	To record deposits and withdrawals. 
•	To calculate the current account balance. 
•	To store transaction details using arrays. 
•	To validate transactions using if-else statements. 
•	To process multiple transactions using loops. 
•	To apply recursion where appropriate. 
•	To generate a simple transaction statement. 

Approach / Methodology:
The program first accepts the user's initial balance and transaction details. Arrays are used to store transaction amounts and related information. If-else statements are used to determine whether a transaction is a deposit or withdrawal and to check whether sufficient balance is available. Loops are used to process multiple transactions and display the stored records. Recursion can be used to repeatedly perform the transaction/menu operation until the user chooses to exit.

Expected Outcome:
The final application will provide a simple way to record transactions, calculate the available balance, and display a basic bank statement while demonstrating the fundamental Java concepts learned in class.
